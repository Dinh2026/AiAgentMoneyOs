## 🎯 AI Agent Money OS là gì?

AI Agent Money OS là một hệ thống AI hoạt động như **25 nhân viên ảo chuyên nghiệp** — bao gồm cả kỹ thuật lẫn kinh doanh — sẵn sàng hỗ trợ bạn 24/7.

Bạn chỉ cần **nói bạn muốn gì**, AI sẽ tự động:
- Phân tích yêu cầu của bạn
- Chọn đúng chuyên gia phù hợp
- Thực hiện công việc với chất lượng chuyên nghiệp

**Không cần kiến thức kỹ thuật. Không cần học lệnh phức tạp.**

## ⚡ Cài Đặt (3 bước)

### Bước 1: Copy thư mục `.agent`

Sao chép toàn bộ thư mục `.agent/` vào thư mục gốc của dự án của bạn.

```
📁 Dự án của bạn/
├── 📁 .agent/          ← Copy thư mục này vào đây
├── 📄 index.html
├── 📄 package.json
└── ...
```

### Bước 2: Mở dự án trong AI Editor

Mở dự án bằng **Gemini Code Assist**, **Cursor**, hoặc bất kỳ AI Editor nào hỗ trợ `.md` rules.

### Bước 3: Bắt đầu sử dụng!

Chỉ cần gõ yêu cầu bằng tiếng Việt. Ví dụ:
```
"Viết copy cho landing page bán khoá học"
```

AI sẽ tự động kích hoạt đúng agent và bắt đầu làm việc.

## ❓ Câu Hỏi Thường Gặp

**Q: Tôi không biết code, có dùng được không?**
> Có! Các lệnh kinh doanh (`/offer`, `/funnel`, `/copy`...) không yêu cầu kiến thức code. Bạn chỉ cần mô tả sản phẩm/dịch vụ của mình.

**Q: AI có viết tiếng Việt không?**
> Có! Tất cả output kinh doanh đều bằng tiếng Việt tự nhiên. Code comments vẫn bằng tiếng Anh theo chuẩn quốc tế.

**Q: Tôi cần chạy tuần tự 12 skill không?**
> Khuyên dùng tuần tự để có kết quả tốt nhất. Nhưng bạn có thể bắt đầu từ bất kỳ skill nào nếu đã có thông tin đầu vào.

**Q: Có thể dùng trên nhiều dự án không?**
> Có! Copy thư mục `.agent/` vào bất kỳ dự án nào.
