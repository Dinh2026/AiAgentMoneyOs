## ⚡ Cài Đặt (Chỉ 2 bước)

### Bước 1: Clone repository

```bash
git clone https://github.com/Dinh2026/AiAgentMoneyOs.git
```

### Bước 2: Copy `.agent` vào dự án

Sao chép thư mục `.agent/` vào thư mục gốc của dự án bạn muốn dùng:

```bash
cp -r AiAgentMoneyOs/.agent /đường-dẫn-dự-án-của-bạn/
```

**Trên Windows:**
```powershell
Copy-Item -Recurse AiAgentMoneyOs\.agent C:\đường-dẫn-dự-án\
```

Sau đó mở dự án bằng **Gemini Code Assist**, **Cursor**, hoặc bất kỳ AI Editor nào — hệ thống sẽ tự động kích hoạt.
